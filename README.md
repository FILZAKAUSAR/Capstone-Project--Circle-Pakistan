# Capstone-Project--Circle-Pakistan

Interactive Power BI dashboard exploring the drivers of life expectancy across
193 countries (2000-2015), built as a capstone project for the
CIRCLE x DataCamp Data Fellowship.

## Live dashboard
coming soon

## Pages
- **Overview:** global KPIs, map, developed vs developing comparison, top and bottom countries
- **Factors:** how Schooling, GDP, Adult Mortality and HIV/AIDS relate to life expectancy
- **Country Insights:** pick a country to see its trend, rank and drivers against the global and continental averages

## Key finding
Developed countries average about 12 years longer life expectancy than developing countries
(79.2 vs 67.1 years, 2000-2015).

## Data
WHO Life Expectancy data from
[Kaggle](https://www.kaggle.com/datasets/kumarajarshi/life-expectancy-who),
cleaned by my teammate Farah in R. A country-to-continent mapping file is included.
